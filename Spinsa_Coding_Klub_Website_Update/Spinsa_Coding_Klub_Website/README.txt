SPINSA CODING KLUB — WEBSITE

Isi paket:
- index.html: website portfolio dengan perkenalan asli Iban Dev dipertahankan.
- assets/: empat gambar yang diberikan pengguna (kalender, game blok, desain galeri, logo Spinsa Coding Klub).
- downloads/BlockyPuzzle.apk: APK game yang diberikan pengguna, disediakan untuk diunduh.
- downloads/KalenderTabung_v3.zip: ZIP project Kalender Tabungan yang diberikan pengguna.
- downloads/KalenderTabung_source.zip: ZIP source Kalender Tabungan dari paket portfolio sebelumnya.

Cara mencoba:
Buka index.html di browser untuk melihat website secara lokal.
Untuk membagikan lewat internet, upload seluruh isi folder ini ke hosting statis seperti GitHub Pages.

Catatan: APK dan project ZIP disertakan apa adanya, belum diaudit keamanan atau diuji instalasi.
